# Projeto API Rest TodoList

## Finalidade do Projeto

Criar uma aplicação back-end utilizando a linguagem Java e framework Spring boot. O projeto consolida conhecimentos de APIs RESTful, focando boas práticas e organização.
Para o gerenciamento de dependências com a integração de bibliotecas e frameworks necessárias para uma fácil configuração, foi utilizada o Maven.
Persistência dos dados em memória foi utilizada o H2 Database Engine.
Implementando segurança de dados do usuário, realizando tratamento de exceções para garantir a integridade e a estabilidade da aplicação.

## Descrição do projeto
Criação de um aplicação de lista de tarefas, onde o usuário poderá gerenciar e otimizar suas tarefas. O usuário realizará:

* criação de um usuário;
* edição de um usuário;
* exclusão de um usuário;

* criação de tarefas;
* edição de tarefas;
* leitura de tarefas;
* exclusão de tarefas.
